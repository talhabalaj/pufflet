# Third-party components

Native Steam authentication helpers, CM connection/session, owned-license/PICS catalogue and protobuf message definitions are adapted from willfaust/Madeira at `279fd0f83170425db002fe25d6bd62f6355f497d`. Their original copyright notices are retained. The pinned original source is available at https://github.com/willfaust/Madeira/tree/279fd0f83170425db002fe25d6bd62f6355f497d; the GPL-3.0-or-later license and Madeira Converter Exception are included in app resources. The app-side account model, macOS Keychain wrapper and SwiftUI grid/sign-in interface were written for this launcher.

Madeira Dock is modified in the Pufflet fork at `49e226565891f2cde7e68721f7a4d4e42e0c18b1` (https://github.com/talhabalaj/madeira-dock/tree/49e226565891f2cde7e68721f7a4d4e42e0c18b1), based on 125hz/madeira-dock at `72558e416a390f3669457930f09a389e54f49556`. The modifications add Valve-managed installs and a persistent client with numeric commands/events, concurrent launch, queue controls, file verification and an offline reconnect grace. Corresponding source is retained as the pinned Git submodule `Research/Madeira/Dock`, including its tests, documentation and agent guidance. GPL, exception, LLVM and MinGW notices are bundled in `dock-notices.txt`. `Runtime/build-headless-host.sh` reproduces the x86-64 PE using LLVM/MinGW 20260421.

Wine/DXMT and their libraries come from the checksum-pinned pufflet-runtime release, built from source by https://github.com/talhabalaj/pufflet-runtime and signed by the explicit runtime packager. Its `crossover` branch holds CodeWeavers' unmodified CrossOver 26.3.0 sources (https://media.codeweavers.com/pub/crossover/source/crossover-sources-26.3.0.tar.gz); `main` adds Pufflet's Wine patches and the build scripts, which pin every other source release (FFmpeg in its LGPL configuration, GStreamer, gnutls, FreeType, SDL2, MoltenVK, the Vulkan loader, DXMT and others). Wine Mono and Wine Gecko are WineHQ's prebuilt add-ons. Wine: https://gitlab.winehq.org/wine/wine. DXMT: https://github.com/3Shain/dxmt. Their licenses and notices are retained in that repository and the source releases it pins. They run separately from the native launcher. Valve client components are downloaded from Valve's official CDN to Application Support, checked against exact upstream sizes and SHA-256 hashes, and are not included in the app bundle. No games, credentials, account configuration or mutable Steam prefix are copied into the app bundle.

Steam artwork is fetched from Steam by App ID and remains Valve/publisher material. Steam and its marks belong to Valve. This launcher is not affiliated with Valve.

Sparkle 2.10.0 is provided by its official checksum-pinned Swift Package Manager binary. Its unchanged package manifest and license are in Packages/Sparkle. Release CI tooling was adapted from Said, a project by the same author.

Alamofire 5.12.2 (MIT), exact Swift Package Manager revision `bda9ed57d72988a3a2ada33d824583541f86eac6`, handles runtime download progress, cancellation, and resumable transfers. Its license is bundled as `Alamofire-LICENSE.txt`. Source: https://github.com/Alamofire/Alamofire/tree/5.12.2.
