A little extra Windows support

Set up Game
Porting Toolkit.

Only needed for DirectX 12 games. Pufflet already includes DirectX 10 and 11 support. Download Apple’s toolkit, then point Pufflet at your copy.

For Apple silicon Macs. Pufflet requires macOS 26 or later. Game compatibility still varies.

1. Download from Apple2. Open the evaluation image3. Add it to Pufflet4. Choose a game’s graphics
1

Download it from Apple.

Open Apple’s Game Porting Toolkit page ↗ and choose Download Game Porting Toolkit. Apple currently advertises Toolkit 4; the version number may change.

Sign in on Apple’s website with your Apple Account (formerly Apple ID). A free developer registration is enough; you do not need the paid Apple Developer Program. If this is your first visit, Apple may ask you to register and review its developer agreement. Read and accept Apple’s terms yourself.

On Apple’s Downloads page, search for Game Porting Toolkit and download the Mac disk image. You can also search for Evaluation environment for Windows games if Apple lists it separately. Keep the downloaded image so you can reinstall later.

2

Open the evaluation image.

Open the downloaded Game Porting Toolkit…dmg. Inside, open Evaluation environment for Windows games…dmg. That second image contains D3DMetal.

Read License.rtf and Read Me.rtf in the evaluation image. Open redist to find its lib folder. Keep that folder complete: it contains both external and wine.

3

Add your copy to Pufflet.

For a permanent setup, copy the entire redist folder from the evaluation image to ~/Library/Application Support/Game Porting Toolkit/. In Finder, use Go → Go to Folder… to open ~/Library/Application Support/, create a Game Porting Toolkit folder, and copy redist inside it. The resulting path is ~/Library/Application Support/Game Porting Toolkit/redist/lib.

Open Pufflet’s Settings → Advanced and find Game Porting Toolkit. Choose Add Toolkit…, then select your copied redist/lib folder. Pufflet also accepts the evaluation environment’s root folder.

Pufflet references the folder you select; it does not copy the files for you. Preserve the full lib folder and its contents. Pufflet checks for the Windows DLLs, their Mac bridge libraries, and the D3DMetal framework together. An incomplete copy will not be offered as ready.

Already installed it?

Pufflet also checks common Game Porting Toolkit locations and mounted evaluation images. If it isn’t detected, select your copy in Settings. A copy that lives only on a disk image will need that image mounted whenever it is used.

4

Choose a game’s graphics.

Open a game’s options in your library, choose Get Info, and use the Graphics picker to choose its backend.

Auto
Uses D3DMetal when Pufflet detects DirectX 12 and a complete toolkit is available. Other games keep DXMT.
DXMT
The built-in choice for DirectX 10 and 11. DXMT does not add DirectX 12 support.
D3DMetal
Uses your Apple toolkit for this game. Try it for a DirectX 12 game or a DirectX 11 game that works better with it.

Some games load DirectX dynamically or through another launcher, so automatic detection can miss them. Select D3DMetal explicitly when you know a game needs DirectX 12. If you change the graphics backend, close the running game first.

If something isn’t ready.

Pufflet can’t find D3DMetal.

Make sure you opened the nested evaluation environment image. Select its root folder or redist/lib. Keep both external and wine inside lib; selecting only a framework or a DLL will not work.

Can I eject the disk image?

If Pufflet is using the files on the mounted image, keep it mounted. For a permanent setup, copy the complete redist folder to ~/Library/Application Support/Game Porting Toolkit/ and select its lib folder with Add Toolkit….

Does this make every DirectX 12 game work?

No. D3DMetal supplies graphics translation; a game can still depend on unsupported Windows features, anti-cheat, hardware capabilities, or launcher behavior. Try the game and retain your working graphics choice.

Why doesn’t Pufflet download it for me?

D3DMetal is Apple’s proprietary software with its own license. Pufflet uses the copy you obtain from Apple. It is not included in Pufflet’s download or Windows support runtime.
