A few things to know.

What does my Mac need?

An Apple silicon Mac running macOS 26 or later, and a Steam library with installed Windows games. Pufflet uses the existing game files.

Will every Steam game work?

Compatibility varies by game. Pufflet uses Wine and DXMT to run Windows games; a game appearing in your library is not a guarantee it will run. The covers shown here are illustrative.

Do I still need Steam?

Yes. You still use your Steam account and library. Installation, verification, and compatibility fallback remain available in desktop Steam.

When can I download Pufflet?

The first notarized release is being prepared. Follow the project on GitHub for updates. This page will offer a download when the release is published.

Is Pufflet free?

Yes. Pufflet is free and open source under GPL-3.0-or-later. It is an independent project, not affiliated with Valve.
