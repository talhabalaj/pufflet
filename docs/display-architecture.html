What must be proven before release?

First: settings survive Wine shutdown, session identity matches, all launch paths obey the same ownership gate, and active work cannot race a change. No game or download is killed to switch profiles.

Before isolation: use two disposable prefixes to prove Steam initialization, DRM/CEG, saves, cloud conflicts, dependencies, content reuse, and rollback. Runtime and content stay shared; mutable Windows state stays separate.

Existing games keep their current environment until explicit migration. Cloud is not a backup. A rollback must preserve newer saves. Download transfer is a separate later gate.

These are example profiles, not verified fixes for Over the Hill. Saved settings do not prove crop-free or sharp rendering.
